# LibreBlox

A free, open-source Android viewer for Roblox (Material 3, Jetpack Compose): browse experiences and people
without logging in — in the spirit of LibreTube.

- Popular/recommended experiences, search, experience pages (stats, screenshots, description)
- User search and profiles (avatar, friends, followers, experiences)
- **Play** opens the official Roblox app (`roblox://`) — LibreBlox does not run games
- Languages: English, Українська; themes: system / light / dark / AMOLED, dynamic colors

> Not affiliated with Roblox Corporation. Data comes from public Roblox web endpoints that are
> unofficial and may change at any time.

Pairs with [Dorfikstrap](https://github.com/dorfandiysoftware-glitch/dorfikstrap), which can download and launch it.
